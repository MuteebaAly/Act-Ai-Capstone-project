# 🎓 StudyMatch AI

> **An AI-Powered Scholarship Discovery Platform that helps students find international scholarships through one intelligent and centralized system.**

---

# 📖 Introduction

StudyMatch AI is a modern web application developed to simplify the scholarship search process for students who wish to study abroad. Instead of spending hours searching through hundreds of university websites, students can use a single platform to discover scholarship opportunities that match their academic profile.

The platform allows users to search scholarships based on country, degree level, field of study, and funding preference. It also provides detailed scholarship information, university details, eligibility criteria, funding information, required documents, and official application links.

StudyMatch AI aims to make scholarship searching faster, easier, and more organized.

---

# ❗ Problem Statement

Students who plan to study abroad often struggle to find authentic scholarship opportunities because information is scattered across multiple university websites. Every university has different admission requirements, funding categories, eligibility criteria, and application deadlines.

As a result:

- Students spend hours searching different websites.
- Scholarship information is difficult to compare.
- Many students miss application deadlines.
- Finding suitable scholarships becomes confusing.
- Students are unsure whether they meet the eligibility requirements.
- There is no single platform that organizes all scholarship information in one place.

---

# 💡 Proposed Solution

StudyMatch AI provides one centralized platform where students can search scholarships based on their academic profile.

Instead of visiting multiple websites, students simply select:

- Preferred Country
- Degree Level
- Field of Study
- Current Academic Status
- Funding Preference

The platform then displays scholarship opportunities that match the student's profile along with university information and application requirements.

---

# 🎯 Objectives

The main objectives of StudyMatch AI are:

- Help students discover international opportunities.

# 🤖 AI Feature

StudyMatch AI includes an AI-powered scholarship recommendation assistant.

The AI analyzes the student's profile and provides personalized scholarship recommendations based on:

- Preferred Country
- Degree Level
- Academic Background
- Funding Preference
- Field of Study

# 🔄 Application Workflow

1. User creates an account or logs in.
2. User enters academic information.
3. User selects preferred country and degree level.
4. User chooses funding preference.
5. The AI analyzes the student's profile.
6. Matching scholarship opportunities are displayed.
7. The user explores scholarship details.
8. The user accesses the official university application page.

# ⚙ Installation Guide

Clone the repository

```bash
git clone https://github.com/MuteebaAly/Act-Ai-Capstone-project.git
```

Navigate into the project

```bash
cd Act-Ai-Capstone-project
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```

Build the project

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
